# 포철 한눈에 — 예약 자동 갱신 배포본

아직 배포·예약 실행이 활성화된 상태가 아닙니다. ZIP에는 실행 코드와 수정된 웹앱이 포함되어 있습니다.
방문자는 로그인하지 않습니다. 사이트 운영자가 최초 설정 때 GitHub 계정으로 로그인해야 합니다.

## 처음 한 번 설정
1. GitHub에 공개 저장소를 만들고 기본 브랜치를 main으로 둡니다. 개인정보는 올리지 마세요.
2. 이 ZIP을 풀고 **안쪽 파일과 .github 폴더**를 저장소 루트에 올립니다. ZIP 자체를 올리면 실행되지 않습니다.
3. Settings → Actions → General → Workflow permissions에서 Read and write permissions를 선택합니다. 조직 정책이나 보호 브랜치가 push를 막는 경우 설정 조정이 필요합니다.
4. Settings → Pages → Source를 GitHub Actions로 선택합니다.
5. Actions → Update and publish → Run workflow를 실행합니다. 모든 단계가 성공한 뒤 Pages에 표시된 주소로 접속합니다.
6. 앱 상단에서 수집 결과를 확인합니다. 실패하면 Actions 로그와 data.json의 errors를 확인하세요. 수집 실패 경고가 있으면 배포가 성공해도 최신 자료가 아닙니다.

## 동작
- 매일 한국시간 오전 6시에 예약 실행합니다. 실제 실행은 지연될 수 있습니다.
- 2025·2026년 졸업생 취업 표와 학과별 자격증 인증 목록을 가져옵니다.
- 원문 표의 rowspan/colspan을 확장하고 회사별 인원 합계가 유형 합계와 일치할 때만 교체합니다.
- 취업률은 제목의 공표값을 읽습니다. 자격증 평균은 만들어내지 않습니다.
- robots.txt 확인 실패/수집 제한, HTTP 오류, 표 구조 변경, 합계 불일치는 해당 항목 갱신을 중단하고 마지막 정상 자료를 유지합니다.
- 브라우저는 접속 시, 화면 복귀 시, 열려 있는 동안 15분 간격으로 서버의 data.json을 다시 읽습니다. 이 버튼/주기는 학교 수집 자체를 실행하지 않습니다.
- 취업 자료는 연도별로 마지막 정상 수집 시각을 표시합니다. 상단은 실패와 오래된 자료를 경고합니다.
- 공개 저장소의 예약 실행은 장기간 활동이 없으면 비활성화될 수 있습니다. Actions에서 주기적으로 실행 기록을 확인하세요.

## 범위와 한계
새 졸업연도 페이지 자동 발견은 지원하지 않습니다. 새 연도는 URL과 화면 선택 항목, 검증 규칙을 추가해야 합니다.
학교 소식은 초기 확인본이며 자동 갱신 대상이 아닙니다. 학생 평균 자격증은 공개 통계가 없어 미확보 상태입니다.
학교 사이트가 브라우저 실행이나 접근 제한을 요구하면 requests 수집은 실패할 수 있습니다. 우회하지 않고 정식 데이터 제공 또는 학교 협조가 필요합니다.
공개 자료라도 학교의 이용 조건을 준수하고, 학교의 중단 요청이 있으면 예약 수집을 중지하세요.

## 검증 상태
샘플 HTML로 병합 셀·합계 오류 차단·자격증 파서를 테스트했습니다. 실제 서버에서 수집/배포를 실행한 것은 아닙니다. 첫 실행 로그와 공식 원문 대조가 필요합니다.
index-auto.html 단독 파일은 화면 미리보기용입니다. 자동 갱신은 ZIP 전체를 배포해야 합니다.
